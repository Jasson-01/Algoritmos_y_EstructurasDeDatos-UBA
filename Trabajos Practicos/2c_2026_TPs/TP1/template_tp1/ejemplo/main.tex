\section{Macros para escribir en LaTeX}

Para facilitar la escritura del trabajo práctico en LaTeX, les proveemos de varias macros que les permitirán escribir especificaciones en lógica de primer orden.
Por ejemplo, podrán hacer uso de comandos que definen los conectores lógicos: $\land, \lor, \implica$ y también los operadores de la lógica trivaluada $\yLuego$, $\oLuego$, $\implicaLuego$.

Además, disponen de comandos para cuantificadores: $\paraTodo{x}{\mathbb{Z}}{x \geq 0 \lor x < 0}$, $\existe{x}{\mathbb{Z}}{x \geq 0}$. A ambos se les puede agregar un \texttt{Largo} al final para que ocupen más de un reglón (junto con "\verb|\\|" para realizar un salto de línea). Tanto los \texttt{requiere} como \texttt{asegura} se pueden escribir en varios renglones o se les puede agregar un \texttt{Corto} al final para que ocupen un solo renglón (en el caso de que no sean largos).

    \paraTodoLargo{i}{\Z}{0 \leq i < |nombreMuyMuyLargoDeSecuencia| \implicaLuego \\ nombreMuyMuyLargoDeSecuencia[i] \in c}
